为什么printk需要Ring Buffer

有没有想过一个问题：为什么 printk() 不直接把字符串输出到串口？而是需要一个ring buffer？
因为串口、console等输出设备非常慢，CPU执行代码的速度远远快于串口发送数据的速度。
CPU 时钟大约为GHZ级别的，而串口的传输速度只有几Mbps。
如果CPU每次的日志都需要等串口等设备同步，那么就会造成的大量的日志积累，拖慢系统的运行。

于是printk会把产生的消息存入ring buffer。实现生产者和消费者解耦的目的。
